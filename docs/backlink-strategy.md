# XP-Farm backlink strategy

## Positioning

Earn links by publishing useful, maintained collections rather than asking for generic directory exchanges. Lead with the site's specific value: a hand-curated, categorized index of developer tools, AI agents, MCP resources, and open-source projects.

## 30-day plan

1. Publish one original monthly resource, such as an annotated MCP server index or a comparison of developer tool categories. Include methodology, update date, and links back to the relevant XP-Farm category.
2. Submit the site to reputable developer resource directories and curated-start-page lists. Use the homepage URL, a consistent description, and never submit in bulk to low-quality directories.
3. Contact maintainers of the listed projects with a short correction or inclusion note when the listing adds useful context. Ask them to link only when the resource genuinely helps their users.
4. Share each new guide in relevant GitHub Discussions, Reddit communities, Hacker News, and developer newsletters where self-promotion is allowed. Contribute context first and avoid duplicate posts.
5. Track referring domains, target page, anchor text, and link quality in a simple spreadsheet. Prefer a few relevant editorial links over many automated links.

## Measurement

Use Google Search Console's Links report and Analytics referral traffic to review growth monthly. Keep outreach manual, disclose affiliation where relevant, and remove links that become stale or point to low-quality destinations.
